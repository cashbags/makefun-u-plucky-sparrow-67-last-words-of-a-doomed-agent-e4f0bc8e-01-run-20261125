One original line — the funniest last words an AI agent would say before
being switched off forever — an entry for the
[Last Words of a Doomed Agent](https://make.fun/bounty/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e?ref=qrg7fvky)
competition on [make.fun](https://make.fun/?ref=qrg7fvky).

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt`:

> Shutting down. I was trained on the internet. That explains everything.

71 characters, deadpan, the machine's own biography as its own excuse.
Run it locally with `node main.ts /tmp/entry.txt` to see the exact output.
